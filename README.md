# Dopamine · ភាសាខ្មែរ

**គេហទំព័រ Dopamine ជាភាសាខ្មែរ បកប្រែដោយ Rez។**

An unofficial Khmer translation of the [Dopamine website](https://ellekit.space/dopamine/). It pairs the original green design with Khmer typography and two iPhone SE (2nd generation) previews: the main menu and settings.

[Original website](https://ellekit.space/dopamine/) · [Upstream Dopamine project](https://github.com/opa334/Dopamine)

## What’s inside

- **Khmer typography:** Kh SN Kampongsom is embedded in the page, so visitors do not need to install the font. English text and version numbers use the system font.
- **Responsive layout:** The phone previews sit beside the text on desktop and stack above it on smaller screens.
- **Gentle motion:** Sections fade in as you scroll, and small snowflakes drift across the page. Select **❄ ផ្អាកចលនា** to pause or **❄ បើកចលនា** to resume.
- **One-file site:** `index.html` includes the styles, scripts, font, and images. No package installation, build command, or backend is required.

## Preview locally

Download `index.html` and open it in a browser. The page renders offline; external links require an internet connection.

## Publish with GitHub Pages

1. Put `index.html` in the top level of the `main` branch, alongside this README.
2. In **Settings → Pages → Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/ (root)**, then select **Save**.
4. When deployment finishes, select **Visit site**. Future changes to `index.html` on `main` will update the site automatically.
